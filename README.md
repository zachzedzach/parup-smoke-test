# The Fourth Club smoke-test site

Static GitHub Pages landing page for The Fourth Club golfer-matching interest test. The site is published to GitHub Pages; the brand name is The Fourth Club.

## Current shared app — November 19, 2026

The profile city also sets the starting area in the course picker. City names accept common state/county suffixes (for example, “Provo,” “Provo, UT,” and “Provo, Utah County”); exact-city courses appear first, followed by nearby courses in that county. The list opens at the matching area, and its scroll position stays anchored when searching or changing order. A compact Utah overview sits beside the list and highlights the region represented by the visible course rows as the list scrolls.

The homepage phone and `/?homescreen=1` run the same app. Read [PRODUCT.md](PRODUCT.md), [DESIGN.md](DESIGN.md), and [docs/LATEST_WORK.md](docs/LATEST_WORK.md) for the current product and handoff. Research and decisions are in [docs/NIGHT_DESIGN_RESEARCH.md](docs/NIGHT_DESIGN_RESEARCH.md).

The first-run app collects a name, city, gender, whole-number handicap slider starting at 0 and ranging to 54, and a short description. It then asks which numbered game description fits, which of the seven score ranges to show, which public Utah courses the golfer plays, and a separate usual start time for each selected weekday. The skill screen and partner filter use the same seven concrete, color-coded 18-hole score descriptions; the second screen makes clear that these are the ranges the golfer is comfortable playing with. Course choices are searchable and multi-select; the Utah overview follows the visible area, and a typed city such as “Provo, UT” starts the list near that county. Weekly start times use 15-minute steps. A separate match-window slider moves in 15-minute increments and shows an example of the earliest and latest round start that would appear around the first selected day’s time. The final preference screens cover usual party size, holes, pace, and four paired round-style choices: conversation, competition, music, and tips. Playing-partner audience is multi-select: visitors can include women golfers, men golfers, or both, with “Everyone” as a shortcut. Public-round visibility is a separate multi-select setting that can exclude women golfers, men golfers, or people who smoke. The optional “Show me rounds without smoking” control only filters example plans shown to the visitor; it does not affect who can see their public rounds.

Completing the profile leads to a specific dated round plan, separate from repeating availability. The golfer can choose a course, date, 15-minute start, holes, cart choice, and whether the plan is public. A public sample plan can receive an example request that the golfer accepts or declines. The app then points to the course to arrange booking. Profiles, course matches, and requests are examples; they are not saved to a real calendar, shared with actual golfers, or sent as notifications. All entries reset on reload. The app does not reserve a tee time or contact a real person.
